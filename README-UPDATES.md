## 💡 小贴士

1. **保存文件后自动更新** - 如果开发服务器在运行，保存文件后浏览器会自动刷新
2. **使用搜索功能** - 在代码编辑器中按 `Ctrl+F` 快速找到要修改的内容
3. **检查控制台** - 如果出错了，按 `F12` 打开浏览器控制台查看错误信息
4. **复制模板** - 总是复制现有工具作为模板，不容易出错
